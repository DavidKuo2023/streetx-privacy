## 1. 引言与适用范围

1.1 StreetX（中文名"街市"，以下简称"**本应用**"或"**我们**"）是一个面向食客与街头摊主的**信息展示与聚合平台**。我们帮助用户发现附近的街头美食摊位，并为摊主提供展示摊位与菜品信息的工具。

1.2 我们深知个人信息对您的重要性，将按照《中华人民共和国个人信息保护法》《网络安全法》《数据安全法》以及（针对海外用户的）《通用数据保护条例》（GDPR）等适用法律法规处理您的个人信息，并遵循以下原则：**权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明**。

1.3 本政策适用于 StreetX 移动应用（Android / iOS）提供的全部服务。请您在使用本应用前仔细阅读并充分理解本政策；**对于与您的权益存在重大关系的条款，我们已采用加粗等方式提示**。

1.4 本应用定位为**信息展示平台**，不提供交易、支付担保、预订或资质审核服务；摊位信息由摊主自行发布，我们不对其真实性做背书（详见《用户协议》）。

## 2. 我们收集的个人信息

我们仅收集为实现具体功能所必需的信息，具体如下：

| 信息类别 | 具体内容 | 收集目的 | 是否必需 |
| --- | --- | --- | --- |
| 账户信息 | 邮箱地址、密码（加密存储） | 注册、登录、找回密码、接收验证码 | 必需（邮箱注册方式） |
| 第三方登录标识 | 华为账号 OpenID/UnionID、昵称、头像；Apple 账号用户标识、邮箱、姓名（仅首次授权） | 快捷登录、账户识别与跨设备恢复 | 使用该登录方式时必需 |
| 个人资料 | 昵称、头像 | 展示个人主页、评价区作者信息 | 可选（有默认值） |
| 位置信息 | 设备定位坐标（粗略/精确） | 发现附近摊位、计算距离、地图展示 | 必需开启才能使用附近功能；拒绝后可使用城市浏览等降级功能 |
| 摊主信息 | 摊位名称、地址、坐标、营业时间、图片；联系方式（手机号，仅摊主） | 摊位展示与食客联系 | 摊主发布摊位时必需 |
| 发布内容 | 菜品名称、价格、图片、原料/调料、过敏原标注；评价文字、评分、图片 | 内容展示 | 发布时必需 |
| 使用记录 | 收藏、屏蔽列表、搜索词、浏览行为 | 收藏功能、内容过滤、产品优化 | 功能必需 |
| 统计埋点 | 事件级行为数据（如页面访问、角色选择、功能使用频次） | 产品改进与统计分析 | 详见第 3.3 条 |
| 购买信息 | Pro 订阅的商品、订单号、交易凭证、购买时间 | 发放与恢复订阅权益 | 购买时必需（不接触您的银行卡信息） |
| 安全与合规记录 | 法律文档同意记录（时间、版本）、设备标识符 | 合规取证、账户安全 | 必需（法定义务） |
| 设备与日志信息 | 设备型号、操作系统版本、应用版本、IP 地址、访问日志 | 排查故障、保障服务安全 | 必需 |

**我们不会收集**：通讯录、短信、通话记录、相册全量照片（仅在您主动上传时读取您选择的图片）、剪贴板内容、生物识别信息。

## 3. 我们如何使用信息

### 3.1 核心功能

- 提供摊位发现、搜索、地图展示、导航跳转服务；
- 实现账户注册、登录（邮箱/华为/Apple）、资料管理；
- 支持您发布摊位、菜品、评价等内容，并展示给其他用户；
- 提供收藏、屏蔽、评价等互动功能；
- 发放、恢复与管理 Pro 订阅权益。

### 3.2 安全保障

- 识别与防范欺诈、滥用、攻击等风险行为；
- 维护服务稳定运行与故障排查。

### 3.3 统计分析

- 我们使用**自建**的统计系统记录功能使用情况（如某功能的使用次数），用于判断产品改进方向；
- 统计事件以匿名或账户标识关联的方式记录，**不用于广告投放，不用于构建营销画像**；
- 如需停止，可通过注销账户或联系我们申请。

### 3.4 我们不会做的事

- **不会**向您发送垃圾营销信息（本应用当前不包含推送营销功能）；
- **不会**将您的个人信息用于本政策未载明的其他目的；如需超出范围使用，我们将再次征得您的同意。

### 5.1 共享原则

- 获得您的**明确同意**；

- 法律法规要求、司法或行政机关依法要求。

## 6. 信息的存储与保护

### 6.1 存储位置

我们的服务器由 InsForge 云服务托管，数据中心位于**新加坡**。如您位于中国大陆，这意味着您的部分个人信息将**跨境传输至新加坡**的服务器存储与处理；我们依据适用法律（如《个人信息保护法》第三章）进行该等传输，并在与云服务商的协议中要求其提供不低于本政策的安全保护水平。针对欧洲经济区用户，相关传输基于标准合同条款（SCC）等合法机制。

### 6.2 存储期限

我们仅在实现目的所必需的期限内保留您的个人信息：

- **账户信息**：账户存续期间持续保存；您注销账户后，我们将在 **30 天内**删除或匿名化处理（法律法规要求保留的除外，如依法需留存的安全日志）；
- **位置信息**：仅用于当次服务响应，不在服务器持久化存储精确轨迹；
- **统计埋点**：最长保留 24 个月，之后聚合化处理；
- **购买记录**：依据财税法规要求保留至法定期限届满。

### 6.3 安全措施

我们采取符合行业标准的安全措施，包括但不限于：

- **传输加密**：客户端与服务器之间采用 HTTPS/TLS 加密传输；
- **存储加密**：密码经不可逆加密存储，数据库访问受行级安全策略（RLS）限制，账户间数据严格隔离；
- **访问控制**：遵循最小权限原则，敏感密钥仅限服务器端使用；
- **安全审计**：对关键数据操作保留审计日志。

尽管有上述措施，互联网环境并非绝对安全。如发生个人信息安全事件，我们将按法律要求及时以推送/公告等方式告知您事件情况及补救措施，并向监管部门报告。

## 7. 您的权利

依据适用法律，您对自己的个人信息享有以下权利：

| 权利 | 说明 | 行使方式 |
| --- | --- | --- |
| 访问与复制 | 查看我们持有的您的个人信息 | 应用内「我的」页面查看资料；或邮件申请 |
| 更正与补充 | 更正不准确的个人信息 | 应用内直接编辑昵称/头像等；或邮件申请 |
| 删除 | 要求删除您的个人信息 | 应用内「我的 → 设置 → 注销账户」；或邮件申请 |
| 撤回同意 | 撤回此前作出的同意（如位置权限） | 系统设置关闭对应权限；撤回不影响此前处理的合法性 |
| 注销账户 | 删除账户及关联数据 | 应用内一键申请，30 天内完成处理 |
| 投诉举报 | 对个人信息处理提出异议 | 联系 streetx@126.com；您也有权向监管部门投诉 |
| 可携带（GDPR）| 获取结构化格式的个人数据副本 | 邮件申请，我们将在 30 日内提供 |
| 限制/反对处理（GDPR）| 限制或反对特定处理活动 | 邮件申请 |

我们将在收到您的请求后 **15 个工作日（最长不超过 30 日）**内响应。

## 8. 未成年人保护

8.1 本应用主要面向成年人。**我们不会主动收集 14 周岁以下儿童的个人信息**；若您为 14 周岁以下儿童，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本应用。

8.2 针对欧洲经济区用户：如您未满 16 周岁（或所在成员国规定的数字同意年龄），请确保已获得监护人同意。

8.3 若我们发现在未事先获得可证实的监护人同意的情况下收集了儿童个人信息，将设法尽快删除相关数据。如您是监护人并有相关疑虑，请联系 streetx@126.com。
